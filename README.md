# Tonight

Source project for a focused evening-planning product.

This public repository contains the source project and supporting resources. Build products, signing files, and distribution archives are intentionally excluded.

## Build locally

Open the project in Xcode, select the appropriate iOS scheme, and run it on an iOS Simulator or connected device. Distribution builds require the matching Apple Developer and App Store Connect configuration.

## Portfolio note

Tonight demonstrates product exploration, mobile UI implementation, source organization, and the iteration required to move an idea toward a usable app.
